title: VectorForce

## Summary

Place a `VectorForce` inside a `Part` to affect it. See the [Physics Movers guide](../../guides/physics-movers.md).

## Properties

- `Force` - [`Vector3`](../datatypes/vector3.md), the force applied each step. Defaults to `0, 0, 0`;
- `Name`, `ClassName`, `Parent`.
