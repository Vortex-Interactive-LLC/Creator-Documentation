## Summary

Place a `Torque` inside a `Part` to affect it. See the [Physics Movers guide](../../guides/physics-movers.md).

## Properties

- `Torque` - [`Vector3`](../datatypes/vector3.md), the torque applied each step. Defaults to `0, 0, 0`;
- `Name`, `ClassName`, `Parent`.
