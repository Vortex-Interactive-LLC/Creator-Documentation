title: StarterCharacterScripts
description: Holds the scripts that are copied into every character.
---

## Summary

Every item inside `StarterCharacterScripts` is copied into each player's character when it spawns, so a [`LocalScript`](./localscript.md) or [`Script`](./script.md) placed here runs once per character and is removed with it. Items that are not archivable are not copied. Use [`StarterPlayerScripts`](./starter-player-scripts.md) for scripts that should run once for the whole session.
