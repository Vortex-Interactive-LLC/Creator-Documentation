## Summary

`GuiService` reports interface settings of the local player. Use it in a `LocalScript` with `game:GetService("GuiService")`.

## Properties

- `PreferredTextSize` - `Enum.PreferredTextSize`, read-only. The text size the player chose in the game's settings: `Medium`, `Large`, `Larger`, or `Largest`. Defaults to `Medium`;
- `Name`, `ClassName`.
